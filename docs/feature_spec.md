**이름이 보이는 곳**: 운영진의 멤버 목록뿐.
→ 검토 화면, 노트, 도움돼요 알림에 작성자 이름과 프로젝트명 노출안됨

**배정 전 아기사자**: 홈에 할 일 대신 "운영진이 배정하고 있어요" 카드가 보이고,
→ 노트·회의 도우미는 바로 이용 가능. 이때 쓴 일지는 "미분류"로 저장됨.

<성장일지 검토 → 공개 흐름>

1. 일지는 AI 정리를 거쳐 운영진 검토 대기열에 들어감
2. 승인되면 작성자가 고른 범위에 맞춰 게시판에 올라감.
3. 돌려받은 일지는 고쳐서 다시 낼 수 있고, 어느 상태든 내 기록과 포트폴리오에는 남음.
